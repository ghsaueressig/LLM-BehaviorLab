# Methodology notes

This document will record the experimental methodology as it is defined.

## Items to specify

- Models and exact model versions
- API providers and access methods
- Questionnaire and source/version
- Experimental conditions and prompt wording
- Number of repetitions
- Generation parameters (temperature, token limits, etc.)
- Response format and validation rules
- Scoring procedure
- Statistical measures
- Data retention and reproducibility procedures

## Important

Keep questionnaire wording, prompts, model identifiers, and generation parameters recorded for every experiment. Do not interpret model responses as evidence of human-like personality.
