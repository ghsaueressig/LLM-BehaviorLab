# LLM-BehaviorLab

**An Experimental Framework for Analyzing Large Language Model Behavior**

LLM-BehaviorLab is a Python-based experimental framework designed to investigate the consistency of Large Language Models (LLMs) and analyze how different prompting instructions influence their generated responses.

## Research objectives

- Evaluate response consistency across repeated experiments.
- Compare behavioral patterns between different LLMs.
- Investigate the influence of prompting instructions.
- Automate questionnaire execution and data collection.
- Generate statistical comparisons and reports.

## Technologies

- Python
- LLM APIs
- SQLite
- Pandas
- Matplotlib
- Pytest

## Project structure

```text
configs/       Experiment and questionnaire configurations
data/          Raw and processed experiment data
docs/          Research and methodology documentation
results/       Generated reports and figures
src/           Main Python application
tests/         Automated tests
```

## Research scope

The project investigates observable patterns in LLM-generated responses. It does not assume that language models possess human personality traits.
